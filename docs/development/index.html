Loki is committed to promoting open source development. In that regard, we will be initiating and supporting open source projects, and this page will serve as the focal point of those activities.
Since we have gotten a lot out of the open source community, we intend to give as much back as we can. We invite you to participate and help make a difference. Join us in making open source work!
Here is an overview of the open source projects we are supporting:
  • OpenAL is a highly acclaimed cross-platform 3D-Audio Library.
  • Simple DirectMedia Layer (SDL) is a cross-platform multimedia development API written and supported by Sam Lantinga, our lead developer.
  • SDL MPEG Player Library (SMPEG) is a general-purpose MPEG video/audio player for Linux.
  • SDL Motion JPEG Library (SMJPEG) is a specialized motion JPEG and audio editing tool for Linux that uses a custom open format.
  • Fenris Online Bugtracking System is a web-based, database-supported system for developers to receive input from users regarding bugs in software, and is based on the work of the Bugzilla project.
  • Setup is an XML- and GTK-based graphic installer utility. This provides an easy-to-use installer interface for the end user.
  • Loki Update Tool is an XML- and GTK-based graphic software update utility. This provides a easy way to update all your Loki products.
  • Loki Uninstall Tool is an XML- and GTK-based graphic software removal utility. This provides an easy-to-use way to uninstall software and free up precious disk space.
  • Loki Patch Tools are a complete set of tools for building an update for software that supports the Loki Update Tool.
