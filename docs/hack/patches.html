These patches apply against the English 1.1 version of Civilization: Call To Power, running on glibc-2.1 systems. Only one patch may be applied at a time.

To install a patch, download the corresponding shell archive, and run it. It will prompt you whether or not you want to install or uninstall the patch. For example:

sh 70-CoolEnhancements.sh

Patches which are listed as save-game compatible can load and save games used by the unpatched 1.1 version of Civilization: Call To Power.

Patches which are listed as network compatible should be able to play with unpatched games over the network. Games that are listed as not having network compatibility should still work if all players have the same patches installed.
