Networking Update
If you were one of the eager beavers to download the Descent3 demo when we first released it on July 22, then you will need to download network-fix.tar.gz and extract it in the descent3_demo directory.
For example:
    cd descent3_demo
    tar zxvf ../network-fix.tar.gz
Many thanks to our mirror site providers! We hope you enjoy playing Descent3!
