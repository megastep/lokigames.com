We have a slight manual correction for Descent3.
The manual describes the Descent3 directory as /usr/local/games/D3 and the binary as D3. The game directory, by default, is actually /usr/local/games/Descent3 and the binary (command) should be descent3.
In addition, we have made the Descent 3 Quick Reference card available in electronic format for you to download in either PDF or GIF format.
