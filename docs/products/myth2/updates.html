We're always hard at work to make sure our products run the way they should, and Myth II: Soulblighter is no exception. He're a list of the available updates and patches to keep you in fighting trim.

Updates and patches

1.17.01 The most current patch for Myth II for Linux is 1.3e and it includes the Chimera add-on! You will need to download and install the 1.3a, 1.3b, 1.3c and 1.3d patches before applying 1.3e. See the README for complete details.

** Note: The Loki Update Tool will automatically download and apply all of the updates in the correct order, so you don't have to do it manually. Check it out!
