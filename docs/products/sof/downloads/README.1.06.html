--- noindex: true --- Soldier of Fortune Patch 1.06 (GOLD) Oct 9, 2000 This patch for Soldier of Fortune for Linux contains the following improvements upon version 1.05 of the game: - Protocol compatible with v1.06 Windows client - Tweaked OpenGL library loading - Upgraded to current OpenAL spec (stable-pre-1-0 no longer needed) - Added support for multi colored names in the score board - Added RED/BLUE team support in CTF - Added CONTROL Deathmatch Option - Added RED/BLUE team support into CONQUER deathmatch - Added downloads of menu .rmf files for deathmatch levels - Added downloads of bot pathing files for deathmatch levels - Fixed remote server calls for any call requiring a string with spaces in it use single quotes instead of double quotes. - General revisions to the AI, improving enemies' awareness, mobility, and tactics. - Multiplayer mode 7, "Conquer the Bunker" - Integrated and optimized Rich Whitehouse's bot code resulting in the first SOF Bot - Waypoint editing system for use with the SOF Bot - Fixed download issue with skies - Changed the game to try to initialize any .PAK file in the game directory, not just pak#.pak files IMPORTANT NOTES Old save games and demos are incompatible with this patch.
