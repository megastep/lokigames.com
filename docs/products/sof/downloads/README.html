--- noindex: true --- Soldier of Fortune Patch 1.05 July 28, 2000 This patch for Soldier of Fortune for Linux contains the following improvements upon version 1.04 of the game: - Respect gl_ext_multitexture - Protocol compatible with v1.05 Windows client - Pure Server option added - Auto-downloading fixed - Audio stuttering between levels fixed - Audio volume tweaks IMPORTANT NOTES This patch breaks compatibility with v1.04 password files. You are advised to remove your previous password file and set your parental control settings again. The password file is located at ~/.loki/sof/password. Old save games and demos are incompatible with this patch. INSTALLING THIS PATCH Just run the script by typing the following from the command line: $ sh sof-1.05-x86.run TECHNICAL SUPPORT Support for Soldier of Fortune for Linux is available from Loki Entertainment Software at: Website: /support Bug Tracking Database: /legacy-services.html#fenris Email: support@lokigames.com Phone: 1-714-508-2140 (9-5 PM US Pacific Time) General Discussion You can also communicate with other Soldier of Fortune for Linux users at: Usenet: /legacy-services.html#news/loki.games.sof
