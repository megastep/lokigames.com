So that you can keep your copy of Civilization: Call to Power up to date, we've assembled a list of available product updates. Just click on the links to download them, then untar them to install.

Updates and patches

Civilization: Call to Power 1.1 Update
Intel x86 and compatibles (3.8 MB)
PowerPC* (2.7 MB)
Alpha** (5 MB)
This update, produced in collaboration with Activision, adds the ability to play Civilization: Call to Power over a network. PowerPC and Alpha users must use this patch to play the game.
* PowerPC version: The PowerPC version is currently still in beta. Networking support are not as yet fully functional. Furthermore, the 1.1 patch can only be applied to a fresh install of v1.0. We are working with Terra Soft Solutions for further PowerPC updates and patches.
** Alpha version: The Alpha version of Civilization: Call to Power does not as yet support networking or scenarios. The Alpha version of Civilization: Call To Power requires a glibc-2.1 based Linux distribution and can only be installed over a fresh install of version 1.0 of the game from CD. The patch has been tested with Linux kernel versions 2.2.11 and 2.3.18. The Linux kernel version 2.2.12 and versions prior to 2.2.11 have known bugs which cause problems with CivCTP. The Alpha port was completed courtesy of Leslie Donaldson.
Civilization: Call to Power Sprite Editor
Intel 386 and compatibles
PowerPC and Alpha versions coming soon
The Sprite Editor is for use with a full version of Civilization: Call to Power. With this tool, users can create and edit their own artwork to use in the game. To use it, download the tar archive, uncompress it, and read the enclosed README file for the license agreement and further instructions.
