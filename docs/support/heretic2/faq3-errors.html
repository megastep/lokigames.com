Errors
Video Memory Protecting
This isn't really an error. The X Direct Graphics Access drivers are just verbose about resetting the graphics modes, which it does just to be safe even if they haven't changed.
The game crashes consistently for me at a certain point. Is there a workaround?
We are working on fixes for these occasional crashes. They usually occur at points where you still need another item or switch to go through that door/etc into the area beyond. Some crashes dealing with switches/buttons etc. can be avoided by shooting the object in question before approaching.
I get an error every time I try to start the game in hardware rendering mode.
Most likely, there is a problem with your gl driver/glide setup. Visit our gl driver page for more detailed information and tips for getting your driver/card to work.
