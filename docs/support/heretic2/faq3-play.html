Game Play
How do I set my path so that it can access the game directory?
export PATH=$PATH:[installation directory]
How can I change my screen size?
Change the "Video Resolution" and "Screen Size" settings under "Video Settings".
How can I maximize graphics speed when running the game?
Under the "Video Settings" submenu, there are several things that you can do. Turn off Paletted Textures. Lower Effects Detail, Contrast, Brightness, or Gamma. Run at a smaller screen size and/or resolution.
Does the Linux version have a map/scenario editor?
Activision released a map/scenario editor with their 1.1 patch. This is included in the Linux 1.1 version of Civ:CTP.
How do I access the console from the game window?
Just hit the "~" key.
Where can I get more game tips?
Have a look at the Heretic II fan page or Activision's site for more information about getting the most out of Heretic II for Linux.
