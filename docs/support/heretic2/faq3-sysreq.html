What are the system requirements for the game? How do the requirements compare to the Windows version?
The listed system requirements are the same. That said, we think Linux users will enjoy all the benefits of Linux while running the game. It's not emulated at all, but a fully native Linux application running under X11.

Minimum system requirements

Linux kernel 2.2.x
GNU C Libraries (glibc) 2.1
Pentium 166 MHz with 3D card,
 or 233 MHz for software rendering
4-speed CD-ROM drive (600 KB/sec sustained transfer rate)
32 MB RAM (64 MB recommended)
260 MB free disk space
XFree86 version 3.3.x, at 16 bpp depth
OSS compatible sound card (for sound)
Does the game use 3D acceleration?
Yes. The game will run in either software mode or with hardware acceleration.
Do I have to have a 3dfx card like I do for Myth 2? Will my TNT2 card work for hardware acceleration?
The hardware 3D acceleration for Heretic II is based on OpenGL. Therefore, any 3D accelerated card with proper OpenGL/Mesa drivers for Linux should work for Heretic II. Right now the 3dfx/voodoo cards are the best suported under Linux, but other drivers are improving rapidly. See our gl drivers page for a discussion on various cards and how to make them work under Linux.
In what environment does the game run? Does it run in X or from the console with SVGALIB?
The Linux version ships with support for X11R6. We may support the framebuffer console in the future and possibly other fullscreen APIs as well If so, a free upgrade will be available for download.
Can the game be played on all distributions of Linux?
We have spent a significant amount of development time ensuring that Heretic II works properly with all major distributions.
Because the game is designed for glibc 2.1, users will probably need to upgrade to the latest version of their distribution.
Can I play on FreeBSD with Linux emulation?
This is not an officially supported platform. However, some have made other games work on FreeBSD 3.1, by recompiling the kernel to support Posix extensions.
We appreciate feedback from users running in FreeBSD. If you'll let us know what hacks you used to make the game work, we'll share those with others. Just drop a line to support@lokigames.com.
Will you be offering support for PPC and Alpha platforms?
Currently, we are not offering support for these platforms for Heretic II.
Does the game support Esound?
Heretic II has native support for esound.
Can I use my SBLive! card with Heretic II?
The problems initially experienced by SBLive! users on some of our games have apparently been solved in the latest open source drivers from Creative Labs.
Does the game fully support X-Windows? Would I be able to run the Linux game using an X-term on a Windows machine?
Some people have been able to do this, but it tends to be slow and requires a very fast network connection between the two machines. It is an unsupported configuration.
Does the game run from the CD?
It does not run from CD, and must be installed onto your hard disk.
