We've made a demo version available for you to test your swordplay and sorcery with Myth II: Soulblighter. The Intel and PowerPC compatible versions are both available now. Here's a list of places where you can download them.
We're working on arranging mirrors, so if you have trouble getting it, keep checking back here for updates on where you can get the demo.
Note: Please be sure to read the Minimum System Requirements on the main product page for Myth II before downloading.

Demo news

17.8.1999 We've been working on bugfixes for the demo version for x86 (a fixed version for PowerPC is coming soon), mainly for keyboard, networking and "blam" issues. A new x86 version is on its way to the mirrors, and the previous version will be moved to /pub/demos/old/. Keep you eye on your local mirror to get the update.
