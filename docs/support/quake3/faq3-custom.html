Customization

Can I use mods, skins and maps on my Linux system that were created on Windows?
Skins and maps are simply TGA and BSP files respectively. They are fully cross-platform. Mods come in two flavors: DLLs and VM bytecode. Mods compiled to DLLs will not work in the Linux version of Quake III. Mods compiled to VM bytecode will work fine.
Will there be any tools on Linux for creating mods?
The QERadiant map editor for Quake III is only available for Windows. The actual mod tools (q3bsp, q3asm, etc.) are currently being ported.

The sources will be released for both map editor and mod tools, but there will not be a Linux Map Editing SDK (like there is for Win32), and the possibility of a Linux Mod Coding SDK is still undetermined.
