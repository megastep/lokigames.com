Are the Windows and Linux versions save-game compatible? Are my Windows saved games playable on the Linux version, and vice versa?
Save game formats are slightly different between the Windows and Linux versions, and are not compatible.
Can I play multiplayer under Linux against users playing Civ:CTP for Windows?
RT2 is not network compatible because the Windows version uses DirectPlay for networking. Since DirectPlay is a Microsoft product and uses proprietary calls which Microsoft has not documented, there is currently no way for us (or for Mac users) to write a game with compatible calls.
Would it be technically possible to use the Windows RT2 CD and then download the Linux binaries?
No, the games use slightly different data file layout, and have some data file differences.
