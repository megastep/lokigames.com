Heavy Gear II for Linux ======================= Patch 1.00a This patch for Heavy Gear II for Linux contains the following improvements upon version 1.0 of the game. - Fixed vertex fog (-x) to fog buildings and other objects - Added multitexturing to show mech damage - Allowed selection of Ammo Fuel Containment - Fixed bug with binding keys to SHIFT + key - Space Mission no longer is fogged with OpenGL fog (-g) - Updated libraries (SDL, OpenAL, SDL_mixer) - Other misc bugfixes INSTALLING THIS PATCH Just run the script by typing the following from the command line : sh hg2-1.0a-x86.run TECHNICAL SUPPORT Support for Heavy Gear II for Linux is available from Loki Entertainment Software at: Website: http://www.lokigames.com/support Bug Tracking Database: http://fenris.lokigames.com Email: support@lokigames.com Phone: 801-356-7629.
