Want to keep your tactical skills in top condition? We thought so. Here is a list of updates for Heroes III for Linux -- download, update, and prepare for added glory. Beta Software We're now offering a beta version (beta5) of the Heroes III Map Editor for Linux here. Please note that this beta is only available for Intel Pentium-compatible computers and it requires either the full version of Heroes III or the demo. The demo will not play custom maps. Updates and Patches There is now a second patch release for the Linux version of Heroes III. This brings the Linux version up to 1.3.1a. For details on what the patch fixes and/or updates, please read the README.

Networking The 1.3.1 version of Heroes III is mostly compatible with the 1.2 version that shipped on the retail CD. However, due to fixes in the game logic in this patch, we strongly advise you to avoid mixing clients from different versions of the game, since some in-game glitches may occur. For playing network games, the best thing is to upgrade all Heroes III installations to version 1.3.1a. Mirrors Linux Tucows
