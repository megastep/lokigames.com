Network Game Play How do I chat in a network game?
Hit the 's' key and type what you want to say. How do I play a network/internet game through a Linux Masquerading firewall?
If you would like to connect to Heretic II Internet servers from behind Linux masquerading, and you have kernel version 2.0.x, you need a kernel patch: ftp://ftp.netcom.com/pub/mu/mumford/loose-udp-2.0.36.patch.gz This has already been fixed in the Linux 2.2.x kernels. Information on why this is necessary can be found at: http://www.alumni.caltech.edu/~dank/peer-nat.html Apply the patch to your 2.0.x kernel and recompile. That should do it! If you DON'T install that patch, Heretic II will not be able to play through your IP masqerading host, and it will not exit gracefully -- it will hang in the "Leaving Lobby" phase. Do the computers have to be on the same subnet to play networked games of CivCTP?
No. You simply need to know the IP address of the server that you want to connect to. Once servers have been added to the Address Book, they will be automatically detected like servers on the local subnet. Is there a way to tell the game a specific IP address to connect to?
Simply add the IP address to your Address Book, and if they're running a server, you should be able to connect to it. How do I connect to an internet server? Is there a list of active servers somewhere?
Gameaholic.com keeps a running list of active game servers here. If I'm blocking UDP traffic, what ports do I need to open up to play Heretic II over my lan?
If you are blocking UDP traffic, you need to open the ports in the range 28900 - 28910 to have the game function properly. On a multihomed host, how do I tell the game which interface to use?
Set the environment variable UUDP_HOSTNAME to the IP address of the interface that you want to use: export UUDP_HOSTNAME=[ip of desired interface] Back to Questions
