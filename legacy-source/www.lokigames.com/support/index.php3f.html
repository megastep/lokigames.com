Direct Assistance is no longer available Remember when seeking help to have information available such as:
  1. Complete product title and version (e.g. sof -v)
  2. Exact error message reported (if any) and a brief description of the problem ­ attach any .sav file if applicable
  3. Linux distribution and version
  4. Computer processor type and speed (e.g. AMD K6-300, Pentium II 233)
  5. RAM and hard disk space available
  6. Video and sound card make and model (e.g. Diamond Stealth 64 video, Sound Blaster 16 sound)
