Errors Video Memory Protecting
This isn't really an error. The X Direct Graphics Access drivers are just verbose about resetting the graphics modes, which it does just to be safe even if they haven't changed. I have a Voodoo3/Banshee card and the game crashes after every mission.
Myth II exposes a bug in the early versions of the Voodoo3/Banshee drivers. Recent versions of these drivers correct the problem and can be downloaded from 3dfxgamers.com. When I try to start Myth II, it hangs immediately.
There is a bug in the libpthread library in some of the newer glibc2.1-based distributions (particularly SuSE 6.1 & SuSE 6.2). We have included a workaround for this in our 1.3a patch. I have a SoundBlaster Live! card, and Myth II crashes as soon as I start it.
The sound library we use exposes a bug in the SoundBlaster Live! driver that crashes the game. We have isolated the bug for Creative Labs, and we are told a fix will be included in the next driver release. In the meantime, we do have a workaround:
  1. Get and install the 1.3b patch for Myth II. (You'll need to have the 1.3a patch installed first.)
  2. Set the SDL_SBLIVE_HACK environment variable to 1. In the bash shell, this is done with `export SDL_SBLIVE_HACK=1`.
