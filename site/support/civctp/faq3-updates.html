Game Updates
Where can I download the update to 1.1?
The 1.1 patch is available here on our website for x86, or we have a beta version for PPC and alpha architectures.
How do I apply the 1.1 update?
NOTE: The following information is similar to the README included with the update.

  1. Unpack the tarball. Anywhere will do, you don't need to save the update directory once you've applied the patch.

    tar -xzvf CivCTP-1.1-x86.tar.gz

  2. Enter the new directory that's created by unpacking the archive.

    cd CivCTP-1.1

  3. Run the 'upgrade' script, giving the location of your Civ:CTP installation as an argument.

    NOTE: You don't have to be logged in as root to run the upgrade, but you do need to have write permissions to the game directory and files. (It's a good idea to run the upgrade script logged in as the same user under which you installed the game.)

    ./upgrade /usr/local/games/CivCTP

  4. [optional] Remove the patch directory.

    cd ../; rm -rf CivCTP-1.1
I have the European version of the game. Why can't I upgrade to 1.1?
The European version of the game comes patched with the 1.1 update. European users won't have to worry about any upgrades until 1.2 is released.
Why can't I load my 1.0 save game files after upgrading to 1.1?
Save game format was changed in the 1.1 update, to make all save game files fully compatible with the windows version save games. So finish that game before upgrading, or upgrade before you start!
Will 1.1 save games be compatible across the three platforms (Alpha, PPC, x86)?
Yes, all three will be save game and network compatible.
Are you going to release a 1.2 update also?
We are working on the 1.2 patch, but haven't set a release date, yet.
