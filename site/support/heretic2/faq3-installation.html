Installation
How do I install the game?
From the README file on the CD:
Mount the Heretic II CD and change the current directory to where it is mounted. Type 'sh setup.sh' to run the install script. Running this script from within X will run the graphical utility.
e.g. Log in as root:
mount -t iso9660 -r /dev/cdrom /mnt/cdrom
cd /mnt/cdrom
sh setup.sh
Do I have to be logged in as root to install the game?
No, but you do have to have write privileges to /usr/local/games (or wherever you install the game).
Do I have to install all of the files to my disk? I don't know if I can spare 270 MB on my hard disk.
The game must be installed to the hard disk to run. You can leave the mpeg movies on the CD, or install them to your hard disk for 50 extra MB of space (for a total of 320 MB).
