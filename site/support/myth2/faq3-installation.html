Installation

Do I have to be logged in as root to install the game?
No, but you do have to have write privileges to /usr/local/games (or wherever you install the game). If you want the installer to place a link in /usr/bin to make startup easier, you'll need write permissions to that directory as well.
How do I install custom maps?
A good example of a custom map is the WWII Recon plugin from Santa's Head.
  1. Download the zip file
  2. Extract it using the `unzip` command
  3. Place the map file (not the copyright message) in:
    • /usr/local/games/myth2/plugins (if you want anyone on the machine to be able to use it)
    • ~/.loki/myth2/plugins (if you will be the only person using it)
  4. Fire up Myth II and select Multi-Player Game
  5. Host a game and select options to change maps
  6. Select one of the WWII Recon maps at the top of your map list, and off you go
After I install the game, it won't start, and gives me a 'Segmentation Fault' error. I can't run the game at all.
Chances are, you're running a Soundblaster Live! card with the beta drivers from Creative Labs. See further down in the faq for a workaround.
The install script gives me an error that it can't find the executables.
There is a slight bug in the install script that only affects systems using a SuSE distribution. The bug causes the script to miscalculate the path to the files when using the GUI installer. To correct this, use the text-based installer with the following:
  • Open an X terminal.
  • Unset your DISPLAY environment variable. In bash, this is done with `unset DISPLAY`.
  • Launch the installer with `sh setup`.
Once the installer finishes, if the link to Myth II was placed in a directory that is in your path, you can start Myth II with the command `myth2`. Otherwise you'll need to specify the location of the link.
What is the difference between the three install sizes?
Minimal Install: 10MB
This installs only the executables allowing you to play the game from the CD. NOTE: This may cause lag in the game on machines with slow CD drives.
Large Install
This install includes everything that is necessary to play the game but does not include the movies.
Full Install
This install is the whole shebang.
